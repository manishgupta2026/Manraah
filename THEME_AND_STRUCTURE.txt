1. DESIGN SYSTEM & THEME: "LAVENDER SANCTUARY"
--------------------------------------------------------------------------------

The visual design is built on a calming Material You / Glassmorphic aesthetic 
tailored for emotional safety, privacy, and inner wellness.

A. TYPOGRAPHY
- Headings: 'Quicksand', sans-serif (warm, rounded, and welcoming)
- Body: 'Work Sans', sans-serif / Inter (clean, high legibility)
- Icons: Google Material Symbols Outlined + curated contextual emojis

B. COLOR PALETTE (Tailwind & CSS Tokens)
- Primary (Lavender Purple):
    DEFAULT: #5F4EA5
    Purple:  #7C6BC4
    Container: #7867C0
    Fixed / Light: #E6DEFF
  Usage: Primary actions, active navigation, gauges, brand elements

- Secondary (Calming Mint):
    DEFAULT: #006B56
    Container / Light: #88F7D6 / #5FCFB0
  Usage: "Flourishing" wellness indicators, success states, balance indicators

- Tertiary (Rose / Peach):
    DEFAULT: #874959
    Container: #A46172
    Light: #FFD9E0 / #F4A6B8 / #F5C99B
  Usage: Emotional tags, gratitude highlights, evening mood gradients

- Surface / Backgrounds:
    Surface: #FDF7FF
    Surface Container Lowest: #FFFFFF
    Surface Container Low:    #F7F1FF
    Surface Container:        #F2EBFF
    Surface Container High:   #ECE4FE
  Usage: Soothing Lavender mist backdrop and floating card containers

- Typography Colors:
    On-Surface (Charcoal): #1D192B
    On-Surface Variant:    #484551
    Outline:               #797582

- Error / Alert:
    DEFAULT: #BA1A1A
    Container: #FFDAD6

C. VISUAL EFFECTS & MICRO-INTERACTIONS
- Glassmorphism (.glass-panel):
    Background: rgba(255, 255, 255, 0.70)
    Backdrop Filter: blur(20px)
    Border: 1px solid rgba(230, 223, 248, 0.50)

- Gradients:
    gradient-primary: linear-gradient(135deg, #7C6BC4 0%, #5F4EA5 100%)
    gradient-mint:    linear-gradient(135deg, #5FCFB0 0%, #006B56 100%)
    gradient-peach:   linear-gradient(135deg, #F5C99B 0%, #F4A6B8 100%)

- Time-of-Day Adaptive Ambiance:
    Morning:   Golden glow (#FFFDF4 -> #FFF5EC -> #EAE4F5)
    Afternoon: Lavender bloom (#F2F4FD -> #ECE6F6 -> #FCE6EC)
    Evening:   Warm sunset (#FFF4E4 -> #FDE4EB -> #ECE7F6)
    Night:     Deep Indigo (#0A0D18 -> #12192C -> #221B3F)

- Ambient Animations:
    Floating leaves (🍃) and blossoms (🌸) floating upward with soft parallax.

3. CORE ARCHITECTURAL PRINCIPLES
================================================================================

1. PERMANENT CATEGORY JOURNEY
   - User chooses 1 of 9 categories during onboarding (e.g. Student, Parent, Young Pro).
   - Stored permanently in the database on user creation.
   - Strictly read-only on dashboards, settings, and profile screens.

2. SANCTUARY SCORE DISCOVERY
   - 3 screening questions for new visitors (stored locally, no DB footprint).
   - 10 category-specific assessment questions (Scores 1 to 5 per question = Max 50).
   - Calculated server-side by /api/assessment and saved to Neon DB.
   - First-time dashboard visit shows a gentle, dismissible SanctuaryScoreModal.

3. SECURITY & PRIVACY
   - Anonymous Sanctuary Names (e.g. "Gentle Bloom") used by default. Real names never required.
   - Server-side validation on all category questions (client categories not trusted blindly).
   - Passwords hashed with Node crypto scrypt.
   - JWT / Session cookies managed with Lax same-site policies.

4. REALTIME SOCKET.IO CLIENT
   - Frontend reads process.env.NEXT_PUBLIC_SOCKET_URL in production.
   - Sensible fallback to http://localhost:3005 in local development.
   - Server CORS explicitly allows production Render origin and localhost.
