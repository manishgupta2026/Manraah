# Parent Dashboard Planning

This document details the interface layout and content structure for the Parent-specific wellness dashboard.

## Dashboard Components Mapping

### 1. Header
- **Greeting:** Dynamic greeting based on current local hour (Morning, Afternoon, Evening, Night).
- **Parent Name:** Displays the parent's name dynamically from user metadata.
- **Today's Date:** Formatted calendar date.
- **Notification Icon:** Badge showing active notices or daily check-in reminders.
- **Profile Avatar:** Quick access to settings or profile edits.

### 2. Daily Wellness Summary
- **Mood Card:** Log or view today's mood (calm, tired, overwhelmed, joyful, etc.) and energy level.
- **Stress Slider:** A scale from 1 to 10 for parents to quickly log current stress.
- **Energy Level:** Numeric out of 10 with a progress meter.
- **Sleep Tracker:** Record hours and sleep quality (deep, light, interrupted).

### 3. Today's Focus
- **AI Recommendation:** Parent-focused actionable wellness suggestion.
- **Wellness Task List:** Toggleable task checkboxes (e.g. 5-min me-time, appreciation statement).
- **Progress Ring:** SVG animation showing % tasks completed.

### 4. Family Wellness
- **Family Wellness Score:** Aggregated score based on activities and check-ins.
- **Family Time Progress:** Goal tracker (e.g. target 60 mins of quality family connection).
- **Weekly Family Challenge:** A cooperative family task (e.g. family walk, board game night).
- **Healthy Communication Reminder:** Empathetic quote or reflection prompt for parenting patience.

### 5. Personal Care
- **Me-Time Tracker:** Log and view dedicated personal time.
- **Water Tracker:** Interactive clickable visual glasses to reach a target of 8 glasses per day.
- **Breathing Exercise:** Shortcut to launch a rhythmic inhale-exhale visualizer.
- **Meditation Shortcut:** Seamless link to parent meditation modules.

### 6. Journal
- **Today's Prompt:** Focus questions like "What made your child laugh today?".
- **Write / Save:** Inline editor box to log journal entries instantly.
- **Previous Logs:** Scrollable history of past parenting insights.

### 7. AI Companion
- **Inline Assistant:** Instantly chat with the wellness companion.
- **Parenting Advice:** Quick-select scenarios to resolve common parent stressors.
- **Panic Button:** "I'm Feeling Overwhelmed" trigger for immediate calming visual guidance.

### 8. Resources
- **Handpicked Content:** Articles, podcasts, and video cards matching parent stress points.

### 9. Weekly Progress
- **Streaks & Charts:** Multi-variable weekly trends showing mood, stress, and task completion.
